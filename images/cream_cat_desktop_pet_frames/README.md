# 白色长毛猫桌宠序列帧素材

本素材包根据用户提供的白色长毛猫形象制作，包含 6 种动作，每种动作 5 帧。

## 目录
- `idle/`：待机（呼吸、眨眼）
- `walk/`：行走
- `run/`：奔跑
- `jump/`：跳跃
- `sit/`：坐下
- `sleep/`：睡觉（带软垫）

每个动作目录包含：
- `frame_001.png` 至 `frame_005.png`：独立 RGBA 透明 PNG，512×512
- `preview.gif`：动作预览动画

## 播放建议
- 按文件名顺序播放 5 帧。
- `manifest.json` 中提供每个动作建议的 FPS。
- 循环动作（待机、行走、奔跑）可循环播放；跳跃、坐下、睡觉可根据状态机决定是否循环或播放一次。

注意：这些帧由同一张动作图谱拆分并统一画布，适合桌宠原型验证；正式上线前建议对个别动作的帧间连贯性和毛发边缘做美术精修。
