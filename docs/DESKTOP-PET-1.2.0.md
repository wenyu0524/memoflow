# MemoFlow 1.2.0 桌宠形象与活动优化

## 行为与造型

- 重新绘制坐姿与四足活动姿态，调整脸型、耳尖、眼睛、瞳孔高光、身体轮廓及尾巴；加入耳朵轻动和视线变化。
- 慢走与奔跑分别使用四足步态；慢走步态周期约 0.64 秒，跑步约 0.26 秒，跑步时身体起伏、头部和后伸的尾巴也会变化。
- 在当前显示器工作区内随机选取二维方向，包含上下、左右和斜向活动，不再限定同一水平线。
- 慢走约 64 逻辑像素/秒，跑步约 275 逻辑像素/秒；部分慢走会在中途突然加速。
- 目的地在工作区内反射，整条插值路径不会越过工作区；支持负坐标显示器和 DPI 缩放。
- 保留拖动、摸摸蹦跳、隐藏及自由活动开关；打开菜单或开始拖动时停止移动。

## 已完成的验证

`node --test tests/pet-motion.test.mjs tests/desktop-config.test.mjs`：11/11 通过。

- 300 次确定性随机采样覆盖四个方向象限、慢走、跑步和中途加速。
- 从四个角分别生成 100 条路径，检查起点、中间点及终点始终在屏幕工作区内。
- 负坐标副屏、任务栏工作区、小于宠物尺寸的工作区与 DPI 速度缩放均有回归检查。
- 独立窗口配置、权限与版本一致性通过。

`tests/pet-animation.browser.html`：4/4 浏览器检查通过，覆盖四足姿态、跑步步频、尾巴姿态差异、待机眨眼与耳朵动作。实际点击“切换朝向”后，活动姿态正确翻转。

实际活动预览的坐标同时发生横向和纵向变化；打开菜单后两次观察的位置一致。停止自由活动后摸摸回应正常，重新开启后可恢复活动。

生产构建通过。Windows 原生拖动、跨显示器活动等仍需要在实际桌面程序中点验，浏览器检查不能替代这些原生行为。
