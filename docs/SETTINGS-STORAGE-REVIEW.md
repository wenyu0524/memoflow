# 设置、启动与本地存储检查

本次只修改源码和浏览器预览，未打包，也未上传代码或图片到 GitHub。

## 功能变更

- 主界面右上角的齿轮设置集中管理：待办提醒、提醒风格、频率、启动时显示桌宠、角色选择。
- 提供“眯了宝”和“罗小黑”两套现有素材，切换后名字、动作、方向与提醒称呼同步更新。
- 提醒设置从旧 localStorage 项迁移到 `pet-settings.json`，独立窗口通过事件同步；不再在桌宠菜单重复设置。
- 启动选项只影响下次启动，仍可通过“桌宠”按钮或托盘手动显示和隐藏。

## 检查发现与修复

| 发现 | 修复 |
| --- | --- |
| 主窗口默认立即显示、初始未居中，页面和窗口状态随后才恢复 | 主窗口初始隐藏并设置默认居中，完成数据加载、窗口行为与页面布局后才显示；已有位置在隐藏期间恢复 |
| 桌宠加载后无条件 `setVisible(true)`，无法遵守默认启动选项 | 由主界面应用启动偏好；桌宠图片和位置准备就绪后才按请求显示，显示请求与就绪状态使用同一互斥锁保护 |
| 隐藏 WebView 中 RAF 可能暂停，单纯等待绘制可能永远不显示 | 等待绘制增加有界超时，防止启动死等 |
| 文件直接覆盖写入，中断可能留下截断 JSON | 原生端临时文件写入并同步后替换正式文件；读写互斥，每次覆盖前保留上个有效版本 `.bak` |
| 快速保存引用可变对象，旧请求可能覆盖新内容 | 写入前捕获不可变快照，按文件排队；前一个请求失败后后续重试仍可运行 |
| 读到损坏 JSON 时浏览器静默回退空数据 | 读取时校验结构，优先恢复有效备份并保留损坏原文；没有有效副本时明确报错并暂停编辑，不用空内容覆盖 |
| 首次保存中断可能只留下完整 `.tmp` 文件 | 原生恢复逻辑同时检查有效备份和临时副本，避免用默认空数据覆盖可恢复内容 |
| 保存失败仍缺少明确提示，用户不能重试 | 共享失败提示保留最新未保存快照并提供“重试保存”；写入失败不显示成功提示 |
| 备忘录延迟保存，退出时最后输入可能未落盘 | 失焦/页面隐藏时刷新防抖，托盘退出前提交待办编辑及备忘录、等待写入完成；保存失败时保留应用并显示提示 |
| 完成一次待办编辑会连续保存两次 | 根据编辑结果直接更新或删除，减少重复的整表写入 |
| 富文本允许不需要的标签，纯文本检测使用非惰性容器解析 | 标签和样式白名单，移除主动内容和外部资源，使用惰性 template 解析文本 |
| 生产 CSP 关闭，桌宠窗口也可调用通用写入命令 | 启用仅本地脚本/图片/IPC 的 CSP；应用数据写入和退出命令限制为主窗口；继续保留文件名白名单 |
| npm 依赖存在已知漏洞 | 在原有版本范围内更新 Vue 3.5.45、Vite 8.3.8、nanoid 3.3.20 等兼容修复，更新锁文件；修复后 npm audit 报告 0 个已知漏洞 |

原生临时文件与正式文件位于同一目录，使用标准库替换文件；实现依据见 [Rust fs::rename](https://doc.rust-lang.org/stable/std/fs/fn.rename.html)。CSP 的本地资源和 IPC 配置依据 [Tauri 官方说明](https://v2.tauri.app/security/csp/)。

## 数据位置与保护边界

桌面版仍使用应用数据目录的本地 JSON，浏览器预览使用各自端口隔离的 localStorage。默认示例数据位于仓库 `data/`。没有新增网络同步或上传用户待办、备忘录。

备份用于恢复上一个有效版本，不是长期版本历史；JSON 和备份均未加密，依赖操作系统用户权限保护。原子写入与退出刷新降低中断风险，不保证强制结束进程或硬件损坏时零丢失。此检查不等同于完整渗透测试。
