# MemoFlow 1.5.0

- 默认桌宠更换为“咪了宝”，主界面右上角设置可切换“咪了宝 / 罗小黑”。
- 提醒开关、风格、频率和默认启动桌宠集中到主界面设置，修改实时同步到桌宠窗口。
- 主窗口在位置、布局和数据准备完成后再显示；桌宠按启动偏好及自身准备状态显示。
- 本地保存增加写入队列、原生原子替换、备份恢复、失败提示与重试；退出前提交未完成的编辑。
- 收紧富文本白名单、CSP 及写入权限；更新兼容的 npm 安全修复版本。

详细检查记录见 [设置与存储检查](SETTINGS-STORAGE-REVIEW.md)。该文档记录打包前的验证范围；本版打包另外在 Windows 执行原生编译及 4 项 Rust 存储恢复测试。

运行前先退出托盘中的旧版本。应用标识和原有数据目录保持一致，备份与恢复不会上传用户待办或备忘录。
