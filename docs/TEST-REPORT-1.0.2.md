# MemoFlow 1.0.2 测试记录

日期：2026-11-05。本版按最新要求恢复半透明圆角窗口，取代 1.0.1 的不透明矩形方案。

## 修改

- 原生窗口开启透明与系统阴影；单层 8px 圆角裁切，避免多层圆角背景叠加。浅色/深色面板均使用 94% 不透明度，并保留轻微内边界。
- 彻底删除 Rust 的 `WindowEvent::Moved` 吸附监听及 `set_position`，避免用户拖动和最大化后被程序强制移回。
- 待办列表改为纵向 Flex，所有行禁止收缩；父层使用 `minmax(0, 1fr)`，超出窗口高度的内容在列表内滚动。
- 图标使用透明 PNG，裁切透明留白后等比放大：512×512 画布中主体约 481×508，保留约 2px 的纵向安全边距。重新生成应用 ICO 和托盘 PNG。

## 图标制作

使用内置 ImageGen 做背景透明化，生成结果保存在 `logo/app-icon-transparent.png`；按 Alpha 实际边界裁切、等比缩放的最终图标源为 `logo/app-icon-full.png`。原始 `logo/1.jpg` 保留。

提示词：去除绿色猫咪记事本轮廓外的白色画布，保留封面、猫咪、黑色线条和内部白色书页，使用真实透明背景，不添加文字、物体或白色方框。随后用确定性的资源缩放流程使主体尽量满铺图标画布。

## 限制

测试不等于保证整个项目不存在任何缺陷。多显示器、不同 DPI、安装升级/卸载、长时间运行与系统托盘各项操作未做完整组合覆盖。Windows 系统自带的贴边布局属于操作系统行为，本版移除的是应用自己的自动吸附。
