## 本轮发现并修复

- 外层残留的大字号 span 会撑大行高：改为将字号落实到文本叶节点，并清理空的外层 span；历史数据载入时同步规范化。
- 删除正在编辑且选中文字的待办后，工具栏可能残留：退出编辑、取消编辑和删除时清理选区。
- 快速连续回车可能重复提交新增内容：先清空输入草稿，再等待保存完成。
- 锁定后面板标题仍带有原生拖动标记：锁定时移除标记。
- 长待办在有限高度和窄列下被 Grid 压缩，文字覆盖邻行：设置隐式行按 `max-content` 分配高度。实测长行修复前行高 406px、文字高度 1368.0625px；修复后行高 1384.0625px，完整包含文字和 16px 上下内边距。
